# 주식 포트폴리오 관리 웹앱 — 통합 요구사항 정의서

**기준 문서:** Claude 기획설계서 v1.0 | **작성일:** 2026-04-28

---

## 1. 프로젝트 개요

한국/미국 주식을 통합 관리하는 개인용 포트폴리오 웹앱.
**매수 묶음(Lot) 단위**로 종목을 독립 관리하고, 사용자 정의 매도 전략에 따라 목표 수익률 달성 시 자동으로 매도 계획을 실행하는 것이 핵심이다.

> 핵심 가치: 평균단가(물타기)로 희석되는 방식이 아닌, **매수 시점별 독립 수익률 추적 + 나만의 매도 규칙 적용**

---

## 2. 핵심 용어 정의

| 용어 | 설명 |
|------|------|
| **Lot (매수 묶음)** | 동일 종목이라도 매수 시점이 다르면 별개의 독립 단위로 관리 |
| **부분 매도** | Lot 내 일부 수량만 매도, 잔여분은 계속 독립 추적 |
| **실현 수익** | 매도 완료된 금액에서 발생한 수익 |
| **미실현 수익** | 현재 보유 중인 잔여 수량의 평가 손익 |
| **전략(Strategy)** | 사용자가 만든 분할 매도 규칙 템플릿 |
| **전략 규칙(StrategyRule)** | 전략 내 개별 규칙 (목표 수익률 → 매도 비율) |
| **Lot 규칙(LotRule)** | Lot에 적용된 전략 규칙의 복사본, 전략 변경에 독립 |

---

## 3. 기능 요구사항

### 3-1. 계정 / 인증
- **Google 소셜 로그인** (OAuth2)
- 사용자별 데이터 완전 분리

### 3-2. 자산 입력 및 관리
- 한국(KOSPI, KOSDAQ) + 미국(NASDAQ, NYSE) 주식 동시 관리
- 종목 검색 후 매수 정보 수동 입력 (종목, 매수가, 수량, 통화)
- 동일 종목 재매수 시 **반드시 새 Lot으로 분리** (기존 Lot과 혼합 금지)
- 매수 통화 구분 (KRW / USD), 미국 주식은 ExchangeRate-API로 원화 환산

### 3-3. 수익률 계산
- 현재가 API 연동으로 실시간 수익률 표시
- Lot별 수익률 = `(현재가 - 매수가) / 매수가`
- 전체 포트폴리오 수익률 = `(총 자산 - 총 투자금) / 총 투자금`
  - 총 자산 = 실현 회수금 합계 + 전체 잔여 수량 평가금
- 실현 수익 / 미실현 수익 분리 표시

### 3-4. 매도 전략 (핵심 기능)

#### 전략 구조

```
Strategy (사용자 전략 템플릿)
  └─ StrategyRule (전략 내 규칙들)
       TargetProfitRate: 목표 수익률 (예: 20%)
       SellPercent: 매도 비율 (예: 30%)
       OrderIndex: 실행 순서

LotRule (Lot에 복사 저장된 규칙 — 전략 원본과 독립)
  └─ TargetProfitRate, SellPercent
     IsExecuted: 실행 여부
     ExecutedAt: 실행 일시
```

**핵심 설계 원칙:**
- 전략을 Lot에 적용하는 순간 StrategyRule이 **LotRule로 복사 저장**됨
- 이후 원본 Strategy를 수정해도 **기존 Lot의 규칙은 변경되지 않음**
- 동일 Lot에 직접 규칙을 수동 설정하는 것도 가능 (Strategy 없이 LotRule 직접 입력)

**매도 트리거 로직:**
```
for each Lot:
  for each LotRule (IsExecuted == false):
    if 현재 수익률 >= TargetProfitRate:
      매도 수량 = 잔여 수량 × SellPercent
      SellRecord 기록
      remaining_qty 차감
      LotRule.IsExecuted = true
```

#### 예시

| 단계 | 목표 수익률 | 매도 비율 | 설명 |
|------|------------|----------|------|
| 1차 | +20% | 30% | 1차 목표 도달 시 30% 매도 |
| 2차 | +50% | 50% | 2차 목표 도달 시 잔여의 50% 매도 |

### 3-5. 대시보드
- 총 투자 원금
- 총 평가금액 (실시간)
- 실현 수익 / 미실현 수익
- 전체 수익률
- 포트폴리오 비중 차트
- 오늘 변동 금액/수익률

### 3-6. 매도 히스토리
- 전체 매도 기록 조회
- 어느 Lot에서, 언제, 얼마에, 몇 주 팔았는지
- 월별 / 연도별 실현 수익 통계

### 3-7. 관심 종목 (Watchlist)
- 매수 전 모니터링 종목 등록
- 현재가 실시간 표시
- 관심 종목에서 바로 매수 Lot 등록 가능

### 3-8. 알림
- 목표 수익률 달성 시 브라우저 푸시 알림

### 3-9. 기타
- Lot별 메모 기능
- 모바일 반응형 UI (카드형 디자인, 한 손 조작 가능)

## 4. 기술 스택

| 구분 | 선택 | 이유 |
|------|------|------|
| **Backend** | FastAPI (Python) | 빠른 개발, 금융 라이브러리 풍부, AI 연동 용이 |
| **Frontend** | React + TypeScript | 반응형, React Native 앱 확장 가능 |
| **DB** | PostgreSQL | 안정적, 금융 정형데이터 최적 |
| **인증** | Google OAuth2 + JWT | 소셜 로그인, 웹/앱 공통 |
| **스타일링** | Tailwind CSS | 반응형/다크모드 구현 속도 |
| **컨테이너** | Docker + Docker Compose | Linux 서버 배포, 환경 통일 |
| **웹서버** | Nginx (리버스 프록시) | HTTPS, 도메인, 정적파일 서빙 |
| **주식 API** | yfinance + 한국투자증권 API | 한/미 통합, 무료 |
| **환율 API** | ExchangeRate-API | 미국 주식 원화 환산 |
