🧠 8. 핵심 로직
📈 수익률 계산
수익률 = (현재가 - 매수가) / 매수가
💰 총 수익률
총 투자금 = 모든 매수 합
총 회수금 = 모든 매도 합
현재 평가금 = 남은 금액 기준

총 자산 = 회수금 + 평가금

총 수익률 = (총 자산 - 투자금) / 투자금
🎯 매도 트리거
for each Position:
  for each Rule:
    if 수익률 >= 목표 && 미실행:
        매도 실행
        RemainingAmount 감소
        SellHistory 기록
        Rule 실행처리
